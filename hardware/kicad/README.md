# KiCad workspace

Create a native KiCad project named `FM1-build` here. Initial repository intentionally contains **no fabricated pin-level schematic**.

Recommended sheets: `power`, `processor`, `usb`, `audio`, `display`, `controls`, `leds`.

Add symbols and nets only when grounded in a datasheet and photo/continuity evidence. Mark uncertain connections explicitly and maintain a verification table in `docs/REVERSE_ENGINEERING.md`.
